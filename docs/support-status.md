# 支持状态与已知限制

中书通过 GitHub Releases 开源分发。0.1.x 阶段优先面向愿意提供反馈的 Rime 用户；本页把构建要求与实测范围分开记录。

| 项目 | 0.1.5 的验证范围 |
| --- | --- |
| 构建目标 | macOS 14 起，安装包包含 arm64 和 x86_64 |
| 本轮自动测试环境 | Apple Silicon，macOS 27.2，Xcode 27.1 |
| 引擎回放 | 测试方案、雾凇全拼、小鹤双拼、全新目录下的朙月拼音 |
| 候选窗 | 本地快照、鼠须管绘制与位置对照；保留旧系统基线，27.2 使用独立参考集 |
| 尚缺实机记录 | Intel、macOS 14/15/26、多用户登录，以及各主流应用的完整长期验收 |

## 已知限制

- macOS 27.2 的隐式回退字体在竖排中可能显示错误字形。中书在该系统及后续版本中先确定每个组合字符的实际字体再排版；字形恢复正确，部分主题的竖排宽度会与旧版不同。
- 从旧版遗留的外部配置链接可读取但不能在设置页保存。先将它替换为独立文件；新导入会自动复制链接内容。失效或循环链接会跳过并列出。
- 设置里的预览目前展示配色和参数，尚不是实时候选窗预览。设置界面主要为简体中文，辅助功能和其他语言还需要完善。
- 大配置和大词库的导入、校验尚无响应时间承诺。方案／深浅色切换、长时间运行的会话数量与内存，需要继续专项验证。
- 更新后的菜单刷新已有本机升级验证，但仍需要更多系统与多用户环境的验收。失败时见 [恢复步骤](recovery.md)。

## 公测记录

每个报告至少记录版本、系统与芯片、应用、方案、是否为干净安装和复现步骤。按 [手动清单](manual-checklist.md) 覆盖首次安装、旧版更新、迁移、输入／选词、睡眠唤醒、多屏／全屏和卸载重装。

只有实际完成的项目才能标为通过；构建为 universal 或 TIS 报告 enabled 都不能代替实机输入与菜单检查。提交报告时使用虚构输入与最小配置，不提供完整用户词库。
