# 0012 设置界面：简单操作，完整功能

日期：2026-10-28

0.2.0 重做设置应用的布局和交互。输入方案、外观、快捷键为日常入口，导入配置单独成页。侧栏沿用中书图标及朱红强调色，内容使用适应深浅色的背景、卡片和原生控件。预览用独立测试目录验收，开发应用使用 Build 标识和 .noindex 构建目录。

## 真实预览与主题副本

`ScribeUI.CandidatePreview` 在无窗口环境下使用正式候选窗的文字排版和绘制代码。示例候选不连接输入会话、不打开词库。透明背景与阴影由预览画布呈现；大尺寸候选按画布空间缩小。原输入法的候选窗逻辑不变。

直接修改通用外观可能被主题自身的 style 覆盖。“自定义外观”从所选浅色／深色预设生成独立的 Scribe 主题副本，避开已有 ID，保留配色与样式，并将后续样式修改写入副本。系统配色仍保持原生，混用系统配色与自定义深色时两者均应用样式。方案强制指定主题时明确提示，不能假装通用主题能覆盖它。

创建主题和修改其子项合并为最终整项后保存，避免校验已被子项覆盖的旧值。测试覆盖原配色保留、名称冲突、原生主题、方案覆盖、浅深色混用，以及实际保存后重新部署与预览一致。

## 更新时接续设置（0.2.1）

安装器在 receipt 完成后的任务里通知设置应用。设置进程也定时读取磁盘上的 Info.plist，避免 Bundle 缓存把新版本误认成旧版。两次读到一致的新构建、父应用与 helper 版本一致后才开始交接。

旧窗口先停止编辑，把草稿写入用户自己的 `~/Library/Application Support/io.github.itvx.inputmethod.Scribe.Settings/SettingsHandoff`（目录 0700、文件 0600）。新实例重新加载配置，恢复草稿并确认接收；旧实例提交交接后才退出，新实例此时才允许编辑。记录采用文件锁和原子替换，避免超时取消与确认同时发生。启动失败保留原窗口，接收后进程异常退出可从持久草稿恢复。恢复的草稿在编辑期间更新，全部保存或撤销后删除。

草稿保留两个配置文件的原始冲突基线，恢复不意味着授权覆盖安装期间的外部编辑。数字、字体、候选格式和安装配方保留原始文字；无效数字仍可继续编辑，不能误保存为截断后的数值。方案和快捷键只传递有修改的页面，未修改的页面读取磁盘现值。

导入及其报告、打开的模态窗口、快捷键录制和输入法 marked text 会推迟交接。交接不会自动执行导入或配置转换，不向输入法广播配置变更，也不把草稿写入 YAML 或同步目录。

0.2.0 及更早版本没有协作协议，无法安全读取其内存草稿。首次升级自动打开新版并保留旧窗口，提供返回旧窗口的入口；不强制终止旧进程。以后的更新可完整自动接续。输入法菜单优先激活相同安装路径下最新启动的设置实例。

验证：`ScribeSettingsTests` 覆盖真实模型草稿往返、外部修改冲突、正常确认、超时、迟到接收、启动失败、接收方退出、崩溃恢复、导入与交互延迟、权限、损坏记录和旧版本兼容。发布包检查协议标记、安装完成 hook，以及 staging helper 不得影响已安装窗口。原生窗口验收使用独立 Build 标识、临时配置和 `.noindex` 应用副本。
