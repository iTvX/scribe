# 0012 设置界面：简单操作，完整功能

日期：2026-10-28

0.2.0 重做设置应用的布局和交互。输入方案、外观、快捷键为日常入口，导入配置单独成页。侧栏沿用中书图标及朱红强调色，内容使用适应深浅色的背景、卡片和原生控件。预览用独立测试目录验收，开发应用使用 Build 标识和 .noindex 构建目录。

## 功能位置

| 功能 | 新入口 |
| --- | --- |
| 方案列表、当前与默认方案 | 输入方案 → 常用方案 |
| 添加方案 | 可搜索的添加窗口，支持名称及标识 |
| 调整顺序、设为默认、移除 | 拖动方案行，或该行的操作菜单；保留至少一项 |
| 每页候选数、方案覆盖提示 | 输入方案 → 候选数量 |
| plum 配方、工具路径、复制命令 | 输入方案 → 安装更多方案 |
| 浅色、深色主题 | 外观 → 主题配色 |
| 主题覆盖下的字号、布局等调整 | 外观 → 自定义外观，先复制主题并保留原主题 |
| 排列、文字方向、状态提示、行内编码／候选、半透明、翻页按钮、尺寸记忆 | 外观 → 排列与显示 |
| 字体、三种字号、候选格式 | 外观 → 字体与文字 |
| 圆角、高亮圆角、行距、编码间距、内边距、阴影、透明度 | 外观 → 间距与细节 |
| 配置来源、方案／主题覆盖提示、单项恢复默认 | 对应设置行的来源详情及恢复操作 |
| 兼容转换、逐项预览、无法转换的项目 | 外观 → 兼容与配置转换 |
| 录制、取消、删除快捷键 | 快捷键 → 切换输入方案 |

| 来源目录、备份确认、导入重试与进度 | 导入配置 |
| 文件分类、跳过原因、链接提示、用户词合并状态、安装及同步信息 | 导入完成报告 |

页面切换保留草稿，侧栏标出哪些页面有修改。保存只影响当前页面对应的配置，继续使用已有校验、外部编辑冲突保护和原子写入。

## 真实预览与主题副本

`ScribeUI.CandidatePreview` 在无窗口环境下使用正式候选窗的文字排版和绘制代码。示例候选不连接输入会话、不打开词库。透明背景与阴影由预览画布呈现；大尺寸候选按画布空间缩小。原输入法的候选窗逻辑不变。

直接修改通用外观可能被主题自身的 style 覆盖。“自定义外观”从所选浅色／深色预设生成独立的 Scribe 主题副本，避开已有 ID，保留配色与样式，并将后续样式修改写入副本。系统配色仍保持原生，混用系统配色与自定义深色时两者均应用样式。方案强制指定主题时明确提示，不能假装通用主题能覆盖它。

创建主题和修改其子项合并为最终整项后保存，避免校验已被子项覆盖的旧值。测试覆盖原配色保留、名称冲突、原生主题、方案覆盖、浅深色混用，以及实际保存后重新部署与预览一致。
